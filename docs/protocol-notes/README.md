# Protocol notes

Working notes on IMAP, POP3, and SMTP server behavior: RFC references,
capability matrices, and observed quirks of real-world servers (Dovecot,
Cyrus, Exchange, common providers). These notes feed the adapter
implementations in `crates/mail-imap`, `crates/mail-pop3`, and
`crates/mail-smtp`.

Empty until phase 2 begins.
